# 墨墨每日学习流程

本 Skill 依赖本地 `maimemo_*` MCP 工具。它不保存凭证、不调用 HTTP API、不直接读写 SQLite，也不修改墨墨账号。

## 分工：App 负责记，这里负责考错题与讲解

正式复习在墨墨 App 里完成，App 会为每个词记录当天第一次作答：`FAMILIAR`（认识）、`VAGUE`（模糊）、`FORGET`（忘记）。本 Skill **不重复 App 已经做完的检查**：

- 不逐词讲解，不让用户逐词确认「我会了」；
- 只考 App 判定为**没记住**的词，`FAMILIAR` 的词一律不考；
- 讲解按需：用户问到哪个词就讲哪个。

## 每天的开场

1. 调用 `maimemo_get_day_state`：
   - `decision: "finish-in-app"` → 今天还有待学词，提醒用户先去 App 完成正式复习，**不得用出题代替**；
   - `decision: "ready"` → 今天已复习完，继续；
   - `decision: "nothing-due"` → 今天没有待学词，工具已顺手把计划读到最新，直接进入出题或按需讲解。
2. 调用 `maimemo_sync_today_snapshot` 保存当天词表，返回里的 `responseCounts` 就是各作答结果的词数。

## 出题：从整个镜像取词，每天固定题量

出题范围**不是今天学的词，而是本地镜像里的整个词表**（墨墨的规划词，回填已证明覆盖完整）。今天刚背的词反而**不进候选**——短期记忆还在，考它没有检索价值。真正值得考的是「学过一段时间、已经有点忘了」的词。

取词只用一条命令：

```
maimemo_list_quiz_candidates({ limit: 20 })
```

它已经按不熟程度排好序并给了每个词的入选理由（`reason`），不要再自己拼条件：

| 优先级 | 理由 | 判据 |
|---:|---|---|
| 1 | `本地错题` | 错题本里未消除的词 |
| 2 | `墨墨标记顽固` | `tags` 含 `STICKING` |
| 3 | `今天复习忘记` | 今天 App 判 `FORGET` 的**复习**词 |
| 4 | `今天复习模糊` | 今天 App 判 `VAGUE` 的**复习**词 |
| 5 | `学得少` | `study_count ≤ 2` |
| 6 | `间隔较久` | 其余，且距上次学习至少 `minDaysSinceStudy` 天（默认 1） |

工具已经做了三件事，不要绕过它：**排除今天新学的词**、**要求距上次学习有间隔**（`minDaysSinceStudy`，默认 1 天）、**同层里距上次学习越久越靠前**。默认只考间隔 1 天以上的词；用户想考得更早的词就调小 `minDaysSinceStudy`。

每天固定 **20 题**（用户可指定别的数量，但**单批最多 50 题**）：**不要 n 个词出 n 道题**，候选再多也只取 20 个，取多少出多少；候选不足 20 就有多少出多少。

**没考到的词不需要记账。** 墨墨自己的 SRS 会继续把它们排进之后每一天的词表，那天它们带着新的作答结果重新进入候选池。覆盖面由 App 的复习排程保证，本 Skill 不另建状态。

**只在用户要求开始当天流程或明确要题时出题，不得擅自出题。** 本地镜像只覆盖已验证范围时，必须按已验证范围描述范围，不得声称覆盖全部。

## 题型：只出选择题，不出对译题

**禁止**出「中文猜英语」「英语猜中文」这类词义对译题——给中文选英文词、给英文词选中文释义，都属于这类。App 已经在考这件事，再考一遍没有新信息。

下面五类是各英语考试词汇题的共同形态，**通用出题即可，不针对某一门考试做风格偏移**。全部做成四选一：

| 题型 | 题干 | 选项 |
|---|---|---|
| **语境选词** | 一个英文句子（目标词处挖空） | 4 个词：正确词 + 形近/近义干扰项 |
| **近义替换** | 一句英文，目标词用 `**粗体**` 标出 | 4 个**英文**近义词或英文释义短语 |
| **搭配填空** | 一句英文，空出搭配的一部分（如 `___ price`） | 4 个词 |
| **形近辨析** | 给出该词的**英文**释义或语境 | 4 个形近词 |
| **熟词僻义** | 一句英文，目标词用的是**生僻义项** | 4 个**英文**释义：正确项是僻义，干扰项放该词的**常见义**与其他义项 |

硬约束：

- **题干只放英文语境，不得出现中文。** 更不许写「括号里给词根 X，该填哪个形式？」这类中文指令——那等于把答案和考点一起交出去。中文一律只出现在答完之后的解析里。
- **不出「给词根选词形」这类构词题**：词根一给出来，答案就只剩机械变形，没有检索价值。
- **题干里不得出现该词的中文释义**，否则又变成对译题。
- 选项 `label` 只放词或短语本身，`description` 里**不要写释义或提示**，等于泄题。
- 每题 4 个选项、1 个正确答案；不用「以上都对」这类无效选项。
- 干扰项优先取 `maimemo_find_similar_words` 返回的本地计划词，不得编造不存在的词；`熟词僻义` 的干扰项取该词的常见义与其他义项。该工具没有合适候选时，改用同义或同词根角度出题，并在解析里说明依据。
- **不做需要语篇的题型**（成篇完形填空、阅读词汇题、写作）：本工具只有词表，没有语料，造出的长文质量不可控。

## 怎么问：默认一题一题，用户可指定批量

默认**一次只问一题**，每题都通过页面弹窗工具 `ask_user_question` 呈现，然后停下等用户作答。用户没有要求批量时，不得把整套题一次性写进回复。

用户明确要求“一次性出完”“批量出题”等批量模式时，以用户指定的数量和呈现方式为准。批量题目之后只说“请按题号顺序回复答案”，**不得提供任何作答示例**，也不得展示答案序列、示范选项字母或其他可能泄露答案的格式提示。只要用户回复与题号顺序的对应关系清楚，就直接判题，不要求重新格式化。

- `question` 放题干；`options` 放候选答案。
- 需要用户自己输入的题：不给 `options`，答案会回到 `custom` 字段。
- 每题给稳定的 `id`（`q1`、`q2`…），便于回看与统计。
- 用户答完先判对错，**再**给该题的答案与解析；题干里不得夹带答案。**题目、答案、解析必须分离**：一次只给题目。
- **无论答对还是答错，每题解析都必须包含以下内容**：
  1. 题目完整中文翻译；
  2. 目标词或短语的中文释义（含词性），并指出本题考查的具体义项、搭配或语法功能；
  3. 四个选项逐项辨析：分别给出中文含义，并结合本题语境说明为什么正确或不正确。不能只解释正确选项，也不能只写答案字母。

  答对也要完整解析——这样才能区分“这次蒙对了”和“真的会了”。批量模式下，在用户提交整批答案后按题号逐题给出同样完整的解析。
- 若当前环境没有 `ask_user_question`，默认退化为**一次一题**的普通消息提问；用户明确要求批量模式时，仍按上面的批量规则执行。

## 错题与日报

**只记错题，不留答题流水。**

- 每题答错后立刻调用 `maimemo_record_quiz_mistakes`，带上该词的 `wordId`、`spelling`、题干 `prompt` 与题型 `type`。同一个词再错只累计次数，不新增记录。
- 答对的词**不写任何记录**；只有当它本来就在错题本里时，才把它放进 `cleared` 标记消除。
- 整批答完再调用一次（把本次所有错题一次性写入也可以，但中途中断会丢）。

接着生成**今日日报**，包含：

1. 本次题数与答对/答错；
2. **错词清单**：拼写、本次错在哪种题型、**错题本里累计错了几次**（用 `maimemo_list_quiz_mistakes` 读历史）；
3. **需要加强的知识点**：从错词里归纳共性——哪几个是形近混淆、哪个搭配族没记牢、哪类义项反复错；
4. 错题本当前规模（未消除 / 已消除）。

日报是生成内容，必须标明**不是墨墨账号原文**。

**日报落盘成文件，不要只留在对话里。** 用 `write` 写到工作区的 `reports/` 目录，文件名 `momo-YYYY-MM-DD.md`（北京时间日期）：

- 每天一个文件，同名文件直接覆盖——当天重做一批就以最后一批为准；
- 文件开头写日期、题数、对错数与错题本规模，正文放错词清单与「需要加强的知识点」；
- 这是**给人读的文档**，写给下一次的自己看：写得具体（哪个词、错在哪种题型、该补哪个搭配），不要写「注意加强记忆」这类空话；
- 结构化的事实（哪个词错了几次）已经在数据库里，日报不要试图代替它，只写归纳与判断。

数据库负责可查询的事实，`reports/` 负责给人读的过程记录——两者都留着，不要只留一个。

## 详解：按需触发

用户问到某个词时才讲解，不主动逐词铺开。讲解包含核心词义与词性、常见搭配、易混点或记忆提示。

**例句的触发规则**（前置条件是「该词今天不是 `FAMILIAR`」）：

| 情况 | 例句 |
|---|---|
| 该词今天 `FAMILIAR` | **不给例句**，不论单义还是多义。用户明确索要时才给。 |
| 非 `FAMILIAR`，且义项 ≥ 2（多义） | **每个义项至少一条**，一条只体现一个义项 |
| 非 `FAMILIAR`，且今天 `FORGET` | 至少一条 |

例句要求：完整自然句而不是短语；该义项在句中有可辨认的语境线索；带中文翻译；不写「This is a challenge for us.」这类无信息量的万能句。

## 来源标注

墨墨开放接口只提供词 id、拼写、作答结果与学习记录，**没有释义与例句**（`/memo/interpretations`、`/memo/phrases`、`/memo/notes` 只返回账号里自己创建的内容，通常是空的），也**没有词书/考试类型接口**。因此释义、例句、题目、解析与日报全部由本 Skill 生成，必须明确标注**不是墨墨账号原文**。

## 账号写入

第一版不支持账号写入：加词、改复习状态、云词本都没有对应工具。用户提出时如实说明，并提示这些操作在 App 内完成。
